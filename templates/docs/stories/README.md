# Stories

One file per story, named `<epic>.<n>-<slug>.md` (for example `1.1-login.md`). One story = one branch = one PR.

## Template

```markdown
# Story 1.1: <title>

Status: draft | approved | in progress | done

## As a / I want / so that

## Acceptance criteria
1.
2.

## Tasks
- [ ]

## Notes
Architecture references, schema impact (needs an ADR and approval), test plan.
```
